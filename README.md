# DAY 31 · React Router와 페이지 흐름

수업 시작 전에 `oz-react` 폴더의 터미널에서 칩니다.

```bash
git clone -b day31 https://github.com/GoodPineApple/oz-react07.git day31
cd day31/hello-react
npm install
npm run dev
```

## 들어 있는 것

- `hello-react/` — DAY 30 실습 01까지 한 코드 (실습 01에서 씀)
- `todo-react/` — DAY 30 실습 02까지 한 코드 (실습 02에서 씀)

실습 02는 `cd ../todo-react`로 옮겨서 다시 `npm install`을 합니다.
