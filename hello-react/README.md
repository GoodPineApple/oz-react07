# hello-react

Vite로 만든 React 연습 프로젝트입니다. (DAY 27)

## 실행 방법

Node.js 20.19 이상 또는 22.12 이상이 필요합니다.
만들 때 쓴 판은 Node.js 26.11.1입니다.

```bash
npm install
npm run dev
```

터미널에 나온 주소(http://localhost:5173/)를 브라우저로 엽니다.

## 명령어

| 명령어 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 켜기 |
| `npm run build` | `dist` 폴더에 배포할 파일 만들기 |
| `npm run preview` | 만든 `dist`를 미리 보기 |
| `npm run lint` | Oxlint로 코드 검사 |

## 만든 방법

`npm create vite@latest` — React · JavaScript · Oxlint (create-vite 9.2.1, Vite 8.3.4, React 19.3.0)
